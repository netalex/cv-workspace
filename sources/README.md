# Documenti originali

Copiare qui le versioni disponibili senza modificarle. Usare nomi distinguibili,
per esempio anno-mese_destinatario_cv.docx. Registrare ciascun documento in
profile/profile.yaml, sezione sources, con ID, path e note.
Date sconosciute vanno indicate come sconosciute. Conservare gli originali.
I materiali caricati nella chat non sono stati importati in questo progetto.
