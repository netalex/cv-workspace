## Attività in corso ##

### scopo del progetto ###
si tratta di un client per device mobili android di un sistema di spunta colli per autostrasporto calato sulle specifiche esigenze del cliente. in questo caso la toolchain di sviluppo è predefinita nei requisiti. Il sistema si basa pesantemente su un insieme di chiamate REST e sul server dedicato che le genera, entrambi definiti e prodotti dal cliente. Attraverso chiamate a queste API RESTful l'app client gestisce la visualizzazione dei dati di carico e l'invio delle informazioni sull'attività dell'autista (spunta dei colli, conferma consegna.)
Il progetto prevede

* forte predisposizione all'internazionalizzazione (consegna progetto in lingua italiana, ma gestione di tutto il testo a video attraverso un sistema di internazionalizzazione bassato su file esterni di dizionario in futuro sostituibili)
* predisposizione alla gestione dell'hw del dispositivo (si prevede ampliamento delle funzionalità alla lettura codici a barre attraverso la camera del telefono)
* sincronia garantita tra local storage e server REST.
